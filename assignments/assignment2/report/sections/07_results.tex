\section{Results}\label{sec:results}
Sections~\ref{sec:res-cal}--\ref{sec:res-base} preserve the original saved notebook run of the consecutive-command plan described in Section~\ref{sec:alg-plan}; the tracker's reading noise is not seeded, so a new run gives slightly different values (Section~\ref{sec:val-limits}). Sections~\ref{sec:res-cal}--\ref{sec:res-acc} report the main run (seed~1, single-axis plan). Section~\ref{sec:res-seeds} repeats the pipeline over 25 seeds and compares the two plans, and Section~\ref{sec:res-base} evaluates the handout's base-frame definition (notebook, extended evaluation).

\subsection{Handout's base-frame definition}\label{sec:res-base}
The handout defines the forward error relative to the robot base, $(F^*_{\mathrm{ee}}(\vct{\theta}))^{-1}\Fun{ImprovedFwdKins}(\vct{\theta})$. This error contains the error of the unobservable rotation $c$ about $\vct{d}_1$ (Section~\ref{sec:alg-gauge}), which no tracker data can reduce; only the handout's bounds limit it. Table~\ref{tab:res-base} evaluates 600 random configurations over the full joint ranges for seeds 1--8: in the tracker frame, relative to the base with $c$ chosen from the bounds, and relative to the base with the fixed convention $\vct{\phi}_2\cdot\vct{e}_x=0$ ($c=0$). The last pair of error columns gives the inverse error for 30 targets specified relative to the actual base.

In the tracker frame both targets are met over the full joint ranges. Relative to the base they are met for seed~1 only, for the forward and the inverse error alike. The unobservable turn contributes to the base-relative angular error and can produce millimetre-scale position error over a lever arm of about $700$\,mm. If the true turn lies between the accepted endpoints, choosing their midpoint limits its distance to that true turn to half their separation. This does not bound the complete pose error, which also contains axis, tool, distortion and measurement effects. Choosing $c$ from the handout's bounds reduces the base-frame errors by a factor of 2--47 compared with the fixed convention, but it cannot meet the targets when the bounds leave a wide interval. We therefore report the measured base-relative errors and state that these targets are not met for all tested seeds.

\subsection{Additional function tests and controlled experiments}\label{sec:res-controlled}
All 81 automated test cases pass. The additional 35 cases verify independent forward examples, selected distortion values, inverse branch/limit/convergence behavior and rejection of unobservable initialization data (Section~\ref{sec:validation}). The inverse-convergence, invalid-target and four unobservable-data cases exposed missing checks, which have been added.

Table~\ref{tab:controlled-results} summarizes the separate controlled experiment of Section~\ref{sec:controlled-sensitivity}; Figure~\ref{fig:kinematics-sensitivity} includes all settings. Each number is mean tracker-frame forward RMSE over six seeds, evaluated on the same 100 held-out full-range commands. It is not a maximum-error compliance result.

Increasing arrivals from 1 to 64 reduces both errors. At zero random noise, the remaining RMSE is about $0.00431$\,mrad and $0.00337$\,mm: the smooth reference distortion is not exactly represented by the selected linear segments. Doubling both spacings increases the observed position RMSE. Halving the default spacing changes angular RMSE little at this noise level, so finer sampling is not uniformly better in these finite noisy data. These trends apply to the stated reference chain, pose-noise model and six seeds; they do not establish a universal accuracy guarantee.
