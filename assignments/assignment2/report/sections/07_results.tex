\section{Results}\label{sec:results}
All numbers below come from one saved run of the notebook; the tracker's reading noise is not seeded, so a new run gives slightly different values (Section~\ref{sec:val-limits}). Sections~\ref{sec:res-cal}--\ref{sec:res-acc} report the main run (seed~1, single-axis plan). Section~\ref{sec:res-seeds} repeats the pipeline over 25 seeds and compares the two plans, and Section~\ref{sec:res-base} evaluates the handout's base-frame definition (notebook, extended evaluation).

\subsection{Handout's base-frame definition}\label{sec:res-base}
The handout defines the forward error relative to the robot base, $(F^*_{\mathrm{ee}}(\vct{\theta}))^{-1}\Fun{ImprovedFwdKins}(\vct{\theta})$. This error contains the error of the unobservable rotation $c$ about $\vct{d}_1$ (Section~\ref{sec:alg-gauge}), which no tracker data can reduce; only the handout's bounds limit it. Table~\ref{tab:res-base} evaluates 600 random configurations over the full joint ranges for seeds 1--8: in the tracker frame, relative to the base with $c$ chosen from the bounds, and relative to the base with the fixed convention $\vct{\phi}_2\cdot\vct{x}=0$ ($c=0$). The last pair of error columns gives the inverse error for 30 targets specified relative to the actual base.

In the tracker frame both targets are met over the full joint ranges. Relative to the base they are met for seed~1 only, for the forward and the inverse error alike. The angular error is the error of $c$, at most half the interval width, and it reaches millimeters at the lever of about $700$\,mm between the base origin and $\{e\}$. Choosing $c$ from the handout's bounds reduces the base-frame errors by a factor of 2--47 compared with the fixed convention, but it cannot meet the targets when the bounds leave a wide interval. We therefore report the base-frame accuracy as achieved rather than met.
